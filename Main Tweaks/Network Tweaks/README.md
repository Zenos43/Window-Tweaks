# Guide to optimize reduce latency and packet loss for competitive games

* Please read the whole guide and don't apply the files immediately.  (UPDATED 29/06/2025)  STILL TESTING NEW FEATURES...
* Offload features help to avoid packet loss but add latency / Low Buffers help to reduce latency but it can give packet loss issues
* Remember to DISABLE UAC and ALLOW TO RUN POWERSHELL SCRIPTS inside your windows for use these scripts Allow Scripts.cmd
* RSS Queues : 2 or 1 queues not more for avoid more delay....
* Run MTU.bat file as last one
* Please feedback me in Issue for improve these files and guide in better way for me and for you all
* Set up Static IP on your gaming machine for more consistent network performance.
* Keep updated your Drivers , Bios and Windows
* Disabling checksum offload will also disable other stateless offloading including Receive Side Scaling (RSS), Receive Segment Coalescing (RSC) and Large Send Offload (LSO).
