Disabling VSync can improve performance and increase FP by reducing the demand on the GPU to synchronize with the monitor's refresh rate. This frees up processing power, especially during high-intensity tasks like gaming leading to smoother and better performance and reduce input lag. Since VSync eliminates the need for constant frame synchronization, it can also decrease latency, allowing for a more responsive experience.
